Messaging App

A Java desktop messaging application with one-to-one and group conversations, contact management, and a Swing-based graphical interface.

Overview

This project is built in Java using Swing. It brings chats, messages, contacts, and user profiles together in a desktop application. Conversations and account data are managed locally in the app; it is not a network-backed messaging service.

Features

Chats and Messaging

Create one-to-one and group chats, send messages, and see recent activity from the chat list. Chat previews show the latest message, its sender and time, and read status for messages sent by the current user.

Within a conversation, users can rename or delete the chat, edit or remove their own messages, and react to messages with emoji reactions.

Contacts and Profiles

Manage contacts with names, usernames, phone numbers, and profile pictures. The contact list can be sorted alphabetically or by recently added, and contact details provide access to conversations.

Users can edit their own profile, choose a profile picture, and switch between accounts in the application.

Search

Search across contact names and usernames, chat names, and message content to find people or return to a conversation.

Saving and Loading Accounts

Save account data to a local file and load it again later from the profile page. This allows users to keep their locally managed accounts and conversations between sessions.
